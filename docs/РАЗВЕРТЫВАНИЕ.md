# Развёртывание «ИППД Контроль» на Windows

## Установка на ноутбук

1. Откройте раздел **Assets** в [выпуске v0.1.0](https://github.com/GnomikNaPony/IPPD-Control/releases/tag/v0.1.0) и скачайте `IPPD-Control-Setup-0.1.0-x64.exe` и `SHA256SUMS.txt`. Установщик предназначен для Windows 11 x64. Он содержит приложение, профили, шаблоны и демонстрационный набор. Для установки и работы приложения Node.js, Office и подключение к интернету не требуются.
2. При передаче на рабочий ноутбук ИТ-служба может сверить контрольную сумму. Откройте PowerShell в папке загрузок и сравните поле `Hash` со строкой из `SHA256SUMS.txt`.

   ```powershell
   Get-FileHash .\IPPD-Control-Setup-0.1.0-x64.exe -Algorithm SHA256
   ```

3. Запустите установщик двойным щелчком. Приложение устанавливается в профиль текущего пользователя и доступно из меню «Пуск» под именем **ИППД Контроль**. Установщик поставляется без цифровой подписи. Если Windows или политика компании блокирует запуск, передайте установщик и его SHA-256 в ИТ-службу для согласования.

ИТ-служба может установить программу в режиме без диалогов из сеанса целевого пользователя.

```powershell
Start-Process -FilePath .\IPPD-Control-Setup-0.1.0-x64.exe -ArgumentList /S -Wait
```

## Проверка после установки

1. Откройте **ИППД Контроль** и нажмите **Загрузить демо-комплект**. Программа подставит дату **01.12.2026**.
2. Нажмите **Извлечь данные →**, отметьте **Извлечённые данные сверены**, затем нажмите **Далее →** и **Запустить проверку**.
3. Ожидаемый итог — **Есть замечания**, во вкладке «Нормоконтроль» — **9 нарушений**. Нажмите **Экспорт HTML…**, сохраните отчёт и откройте его в браузере. Для этого прогона используются синтетические документы.
4. Для проверки рабочих документов используйте профиль, согласованный со специалистом УТП. Подробности — в [инструкции пользователя](ИНСТРУКЦИЯ.md).

## Обновление и удаление

Перед обновлением закройте приложение и запустите установщик следующей версии под тем же пользователем. Сохраняйте экспортированные отчёты в папку рабочих документов по правилам компании. Импортированные профили хранятся в `%APPDATA%\ИППД Контроль\profiles`.

Для удаления откройте **Параметры → Приложения → Установленные приложения → ИППД Контроль 0.1.0 → Удалить**. Эта операция сохраняет данные профиля пользователя и ранее экспортированные отчёты.

## Сборка установщика из Git

Для сборки используйте Windows и Node.js **26.0.0 x64**. Из корня репозитория выполните:

```powershell
npm.cmd ci
npm.cmd run typecheck
npm.cmd test
npm.cmd run dist:win
```

Установщик появится в `dist/`. Контрольная сумма для передачи вычисляется по готовому `.exe`.
