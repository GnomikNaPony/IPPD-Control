# Проверка установщика Windows

| Критерий | Доказательство |
| --- | --- |
| AC-01 | `npm.cmd run dist:win` собрал NSIS x64 с профилями, шаблонами и демо. `7zz t` проверил архив. SHA-256 файла `IPPD-Control-Setup-0.1.0-x64.exe` — `eb18b4927a5484b98ddd04123463d01a3a4c46a61d9560db2e7b0f1879e1de2e`. |
| AC-02 | В Windows 11 ARM64 под эмуляцией x64 проверены тихая установка в профиль пользователя, ярлык «Пуск», запуск установленного приложения, чтение DOCX и PDF, сверка, экспорт HTML, повторная проверка после добавления УММ, переустановка и удаление. Демо показало 9 правил с нарушениями. Переустановка и удаление сохранили файл в каталоге профилей и экспортированный отчёт. |
| AC-03 | [Инструкция по развёртыванию](../../../docs/РАЗВЕРТЫВАНИЕ.md) сверена с именем пакета, путями, фактическим названием установленного приложения и результатом демо. |
| AC-04 | Публикация привязана к тегу [`v0.1.0`](https://github.com/GnomikNaPony/IPPD-Control/releases/tag/v0.1.0) форка. Контроль публикации включает проверку тега и повторную загрузку установщика со сверкой SHA-256. |

`npm run typecheck` и `npm test` прошли на macOS arm64 и Windows с Node.js 26.0.0, 43 теста в каждой среде. Проверка платформы не разрешила сборку `dist:win` на macOS: при пробной кросс-сборке `pdfjs-dist` получил нативную зависимость для хоста. Финальную сборку и проверку установленной версии выполнили в Windows.

Самопроверка конфигурации, путей ресурсов и инструкции пройдена. Установщик без цифровой подписи. Корпоративные политики и физический ноутбук остаются за пределами прогона. Локальная сборка и проверка выполнены.
