# Установщик ИППД Контроль для Windows

## Цель и границы

Подготовить установщик для корпоративного ноутбука, сохранить инструкцию и способ сборки в Git. Исходный проект `slavickozlov-stack/IPPD`, ветка `main`, коммит `120d8af`. Область изменения — упаковка и документация. Риск обычный, установка ограничена текущим пользователем. Целевая платформа для сборки — Windows x64.

## Критерии приёмки

| ID | Результат | Основание и проверка |
| --- | --- | --- |
| AC-01 | Один установщик `.exe` содержит Electron, приложение, профили, шаблоны и демо. | Запрос пользователя и договор `src/main/index.ts` о ресурсах. Собрать NSIS, проверить состав, архитектуру и SHA-256. |
| AC-02 | Установка в профиль пользователя, запуск демо, экспорт HTML и удаление. | Запрос о простом развёртывании и сценарий из `docs/ИНСТРУКЦИЯ.md`. Прогнать установленное приложение в доступной Windows. |
| AC-03 | Инструкция описывает скачивание, установку, проверку, обновление и удаление. | Запрос пользователя. Сверить команды, названия и ожидаемый результат с собранным пакетом. |
| AC-04 | Сборка и инструкция доступны через GitHub вместе со скачиваемым установщиком. | Запрос пользователя. Проверить удалённый коммит, ссылку на выпуск и хеш скачанного файла. |

## Поток сборки и сценарии

`npm ci` → `electron-vite build` → `electron-builder` с целью NSIS x64 → установка в профиль → запуск встроенного демо. При отсутствии корпоративного разрешения на запуск неподписанного файла решение принимает ИТ. Для повторной установки сохраняются профили пользователя. Проверку на корпоративном ноутбуке выполняет его владелец или ИТ. Текущий GitHub-аккаунт имеет право чтения исходного проекта, поэтому публикация предусмотрена в форке.
